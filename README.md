# proof. — Proof, not promises.

Uma loja online de perfumes masculinos desenvolvida como projeto de portefólio Full Stack.

A **proof.** é uma marca fictícia de perfumaria inspirada no conceito de laboratório minimalista. A coleção é composta por dez fragrâncias exclusivas, identificadas por fórmulas numeradas, cada uma com a sua identidade e composição olfativa.

O objetivo deste projeto é desenvolver uma aplicação de e-commerce completa, desde a interface até à API, base de dados e processamento de pagamentos em ambiente de teste.

---

## Identidade da marca

- **Nome:** proof.
- **Slogan:** Proof, not promises.
- **Conceito:** Laboratório minimalista de perfumaria masculina.
- **Coleção:** 10 fórmulas numeradas (Nº 01 a Nº 10).
- **Tipografia:** Space Grotesk e Inter.
- **Cores principais:**
  - Branco: `#FFFFFF`
  - Preto: `#111111`
  - Terracota: `#C4572F`
  - Cinza claro: `#F3F3F1`
  - Cinza médio: `#6B6B6B`

## Decisões técnicas

O projeto utiliza uma estrutura monorepo, mantendo o frontend e o backend no mesmo repositório, mas organizados em aplicações independentes.

**Next.js e TypeScript:** responsáveis pela interface e experiência de utilização da loja.

**ASP.NET Core Web API:** responsável pela lógica de negócio e disponibilização dos serviços através de uma API REST.

**PostgreSQL:** sistema de gestão de base de dados relacional.

**Entity Framework Core:** utilizado para mapear as entidades C# para a base de dados e gerir migrações.

**ASP.NET Identity e JWT:** utilizados para gerir utilizadores, autenticação e autorização.

**Stripe:** utilizado em ambiente de teste para simular pagamentos.
